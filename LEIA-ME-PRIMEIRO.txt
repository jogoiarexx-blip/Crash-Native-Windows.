CRASH NATIVE WINDOWS - BUILD AUTOMATICO

Este repositório compila uma versão Windows x64 de CrashNative.exe.
O arquivo compilado aparece na aba Actions do GitHub. Nao precisa instalar
Visual Studio/CMake no PC para baixar um build ja compilado.

ATENCAO: A versão v0.68.0 ainda depende dos dados da ROM original. Por isso,
o ZIP compilado nao inclui a ROM. Para executar, coloque uma cópia legitima
de sua ROM do GBA como input\crash.gba na pasta extraida, e abra CrashNative.exe.

O jogo entregue no artefato e o motor nativo reconstruido. O runtime que
traduz/executa a ROM ARM/Thumb é outro projeto, ainda experimental.

A compilação por Actions nao constitui validação visual ou garantia de gameplay.

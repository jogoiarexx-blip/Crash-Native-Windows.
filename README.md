# Crash Native Windows — builds automáticos

Este repositório compila programas Windows em GitHub Actions. Há dois caminhos distintos:

- **Crash Native (reconstruído):** motor jogável separado do fluxo original da ROM.
- **Crash ROM Original (experimental):** código ARM/Thumb traduzido pelo Port GBA Builder; ainda não é um port completo.

**Nenhuma ROM será enviada ou distribuída pelo repositório.** Para o jogo carregar seus dados, você precisará fornecer sua própria cópia `input/crash.gba` após baixar o pacote.

A infraestrutura de build está sendo configurada. Não considere uma execução bem-sucedida dos testes sintéticos como comprovação de gameplay completo.
